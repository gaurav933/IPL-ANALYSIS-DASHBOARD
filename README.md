# 🏏 IPL Dashboard (Power BI Project)

## 📌 Project Overview

This project is an **IPL (Indian Premier League) Dashboard** developed using **Microsoft Power BI**. The dashboard provides interactive and insightful visualizations of IPL data, helping users analyze team performance, player statistics, match outcomes, and season-wise trends.

The objective of this project is to transform raw IPL data into **meaningful business and sports insights** through effective data modeling, DAX measures, and visual storytelling.

---

## 📂 Project File

* **IPL DASHBOARD (1).pbix** – Main Power BI dashboard file

---

## 📊 Key Features

* 📅 **Season-wise analysis** of IPL matches
* 🏆 **Team performance** comparison (wins, losses, points)
* 🧢 **Player statistics** (runs, wickets, top performers)
* 📍 **Venue-wise match analysis**
* 📈 Interactive **filters & slicers** for teams, seasons, and players
* ⚡ Dynamic KPIs using **DAX measures**

---

## 🛠 Tools & Technologies Used

* **Microsoft Power BI Desktop**
* **DAX (Data Analysis Expressions)**
* **Power Query** for data cleaning and transformation
* **IPL Dataset** (matches & player-level data)

---

## 🧩 Data Model

* Well-structured **relational data model**
* Fact tables for matches and deliveries
* Dimension tables for teams, players, venues, and seasons
* Optimized relationships for accurate filtering and aggregation

---

## 📐 Measures & Calculations

The dashboard uses custom **DAX measures** for:

* Total Matches
* Total Wins / Losses
* Win Percentage
* Total Runs & Wickets
* Top Scorers & Bowlers
* Season-wise and team-wise KPIs

---

## 🚀 How to Use

1. Install **Microsoft Power BI Desktop**
2. Download or clone this project
3. Open `IPL DASHBOARD (1).pbix`
4. Use slicers to explore teams, seasons, and players
5. Hover and click visuals for deeper insights
